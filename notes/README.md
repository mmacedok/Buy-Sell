# Notes — ideas & works in progress

A shared scratchpad for both of us (you + Claude). Text and images only. Speed over tidiness.

## Where things go

| Folder | What goes there |
|---|---|
| `INBOX.md` | **Anything, fast.** Dump the thought, sort it later (or never). |
| `ideas/` | An idea that grew big enough for its own file. |
| `apps/` | Changes/comments about an app we built, one file per app (e.g. `apps/buy-sell.md`). |
| `images/` | Screenshots, sketches, photos. Link them from any note. |

## Quickest ways to save something

1. **Tell Claude** in any session: *"note: …"* or *"add to buy-sell changes: …"* — Claude writes it here and pushes.
2. **GitHub mobile app / github.com:** open `notes/INBOX.md` → ✏️ edit → type at the top → commit.
3. **Image:** in `notes/images/` tap *Add file → Upload*, then reference it as `![](images/your-file.png)`.

## Format (optional)

```
- 2026-11-07 — short thought here #tag
```
Tags that help later: `#idea` `#change` `#bug` `#later` `#urgent`.
